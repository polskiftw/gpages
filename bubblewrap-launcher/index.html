Bubblewrap Launcher Generator

Click together a sandbox and download a ready-to-edit start-isolated.sh. Choose which host folders it can see, what it can change, and whether it gets network, GPU, CUDA, or desktop access.

Everything happens in this browser tab. Nothing runs on GitHub Pages, and no paths are uploaded. The downloaded script will run locally on Linux with your own user privileges. Start with a preset, adjust the permissions, then inspect the script before running it.

1. Start with a template

Templates fill in examples; your actual host paths are never guessed or scanned by the browser.

2. Identity & paths

These are locations inside the sandbox. A path like /workspace doesn't create a new host folder; only the mounts below connect to your real files. HOME is temporary unless you explicitly mount storage there.

Gentoo Shell MCP bridge

This host folder is automatically mounted read-only at /opt/mcp, separately from your project at /workspace. With no arguments, the launcher executes /opt/mcp/.venv/bin/python /opt/mcp/server.py (stdio). --shell opens a troubleshooting shell; --test checks whether the MCP server imports. Your existing start-gentoo-shell wrapper handles the tunnel and is not created by this generator.

3. Folders, files & mount points

Add real host paths and choose exactly where they appear inside the sandbox.

HOST → SANDBOXPERMISSION

Host paths may start with $HOME/, ~/, or /. Read/write access applies to the directory and its contents; more-specific nested mounts override parents. “Hide (empty)” masks an existing sandbox directory with temporary empty storage. Folder selection must be typed or pasted: webpages cannot browse absolute host paths.

4. Access & system tools

System program visibility

Available commands

Bash, sh, and env are always present. Selected commands are individually mounted into /usr/bin. Libraries and support files remain accessible, so this is not a hardened executable whitelist.

5. Graphics & CUDA

GPU access uses existing device nodes, not a second driver installation. The script discovers NVIDIA devices and CUDA paths when launched, so it can adapt to driver updates.

6. Advanced isolation & environment

Additional environment variables

Environment values are embedded directly into the launcher. Don't save tokens, passwords, or private keys here.
