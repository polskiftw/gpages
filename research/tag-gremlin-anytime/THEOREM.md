# Impossibility of exact universal anytime optimality

## 1. Model M0

Let `Σ` be a finite alphabet. A hidden world `D` is a finite set of distinct strings over `Σ` together with a deterministic total priority order `≻_D` on those strings.

A legal query is any nonempty string `q` over `Σ`.

For a fixed finite response cap `C`, the oracle returns

```text
R_D(q) = the first min(C, |M_D(q)|) members of M_D(q) under ≻_D,
```

where

```text
M_D(q) = { x in D : q occurs as a contiguous substring of x }.
```

The policy observes the returned tag identities in their deterministic order. Optional rank/count metadata may also be returned; the counterexample below assigns it so that it provides no extra pre-decision information and therefore does not affect the proof.

The policy is adaptive: after history

```text
h_t = (q_1, R(q_1), ..., q_t, R(q_t)),
```

it chooses `q_{t+1}` as a function only of `h_t` and fixed model parameters. It is **not** given the user's eventual stopping target `K`.

For an uncertainty class `W` of possible hidden worlds, define `T_P(W,K)` as the worst-case number of oracle queries required by policy `P` to have observed at least `K` distinct tags:

```text
T_P(W,K) = max_{D in W} T_P(D,K).
```

For each target `K`, define the horizon-specific minimax optimum

```text
OPT(W,K) = inf_P T_P(W,K),
```

where the infimum ranges over adaptive policies that may be designed for that `K` but do not know which `D in W` is the real world.

A target-oblivious policy `P*` is **exactly universally anytime-optimal on W** if

```text
T_{P*}(W,K) = OPT(W,K)
```

for every feasible stopping target `K`.

The question is whether such a `P*` can exist for every finite valid instance class.

## 2. Counterexample

Take response cap

```text
C = 4.
```

Consider the two hidden worlds

```text
D0 = {a0, a1, a2, pc, c4, c5, c6, c7}
D1 = {a0, a1, a2, pd, d8, d9, dx, dy}.
```

Use deterministic priority orders

```text
D0: c4 ≻ c5 ≻ c6 ≻ c7 ≻ a0 ≻ a1 ≻ a2 ≻ pc
D1: d8 ≻ d9 ≻ dx ≻ dy ≻ a0 ≻ a1 ≻ a2 ≻ pd.
```

Let

```text
W = {D0, D1}.
```

The critical oracle responses are therefore

```text
query a:
    D0 -> [a0, a1, a2]
    D1 -> [a0, a1, a2]

query p:
    D0 -> [pc]
    D1 -> [pd]

query c:
    D0 -> [c4, c5, c6, c7]
    D1 -> []

query d:
    D0 -> []
    D1 -> [d8, d9, dx, dy].
```

Note that `pc` contains `c`, but it is below the cap in `D0`; likewise `pd` is below the `d*` tags in `D1`.

All other productive queries are nonempty substrings of the displayed tag strings. They are enumerated exhaustively by `verify_counterexample.py`.

## 3. Lemma: target K = 3 forces first query `a`

Because the cap is four, one-query completion of target three is possible in principle.

Query `a` returns three distinct tags in both `D0` and `D1`, so

```text
OPT(W,3) <= 1.
```

Zero queries cannot reveal any tag, hence

```text
OPT(W,3) = 1.
```

Moreover, `a` is the **only** query that returns at least three tags in both worlds. Every other productive substring either:

1. addresses a single common `a*` tag;
2. addresses the marker family and returns at most one tag; or
3. belongs to the `c*` side or `d*` side and therefore returns nothing in the opposite world.

Thus exact target-3 optimality forces

```text
q_1 = a.
```

## 4. Lemma: target K = 5 forces first query `p`

No one query can reveal five tags because `C=4`, so

```text
OPT(W,5) >= 2.
```

There is a two-query policy:

```text
1. query p
2. if response is [pc], query c
   if response is [pd], query d
```

In `D0`, the policy observes `pc` and then four previously unseen `c*` tags. In `D1`, it observes `pd` and then four previously unseen `d*` tags. Therefore

```text
OPT(W,5) = 2.
```

It remains to show that any policy achieving five tags in two queries must start with `p`.

Consider every possible first query other than `p`.

### Case A: the first response is empty in one world

This covers every query that only matches the `c*` side, only the `d*` side, or only one world's marker.

On the world producing the empty response, at most four tags can be returned by the second query because `C=4`. Hence at most four distinct tags can have been observed after two requests. Target five is impossible.

### Case B: the first response is identical in both worlds

The only responses of useful size in this class are generated by the common `a*` family. Query `a` reveals three common tags but does not distinguish `D0` from `D1`.

After that identical history, the second query must be the same in both worlds.

- Query `p` adds only one tag, giving four total.
- A `c`-side query can add tags only in `D0`; the `D1` branch remains at three.
- A `d`-side query is symmetric.
- A query addressing one of the already-seen/common tags adds at most one and cannot reach five.

Thus no identical-response first query can guarantee five discoveries by query two.

### Case C: the first response is nonempty and different in both worlds

In this concrete construction, the only query with a nonempty response in both worlds whose identities differ is `p`: it yields `pc` versus `pd`.

Therefore `p` is the unique first query that permits target five to be guaranteed in two requests.

So exact target-5 optimality forces

```text
q_1 = p.
```

## 5. Theorem

**Theorem.** Under Model M0, there does not exist a target-oblivious adaptive policy that is exactly minimax-optimal at every stopping target.

**Proof.** On uncertainty class `W={D0,D1}`, exact optimality for target `K=3` requires first query `a`, while exact optimality for target `K=5` requires first query `p`. A target-oblivious policy has one first action and cannot choose both. Contradiction. ∎

This is an impossibility at the root information state; no later scheduler sophistication can repair it.

## 6. Arbitrarily large finite datasets

The obstruction is not tied to eight-tag worlds.

For any integer `m >= 0`, define

```text
D0(m) = D0 ∪ {e, ee, eee, ..., e^m}
D1(m) = D1 ∪ {f, ff, fff, ..., f^m}.
```

Both worlds have exactly `8+m` tags.

No padding tag contains `a`, `p`, `c`, or `d`, so the four critical responses are unchanged. Any query touching the `e` padding returns nothing in `D1`; any query touching the `f` padding returns nothing in `D0`. Therefore such a first query falls under Case A of the target-5 lemma and cannot guarantee five discoveries in two requests.

Likewise, no padding query returns three tags in both worlds, so `a` remains the unique one-query target-3 action.

Hence the same contradiction exists for **every finite dataset size `N >= 8`** by setting `m=N-8`.

The two worlds in each pair have the same size. Consequently, even revealing the exact hidden dataset size `N` to the policy would not resolve the stopping-horizon conflict.

## 7. Randomized policies

Randomization does not rescue **exact** anytime optimality under worst-case completion time.

For target three, achieving the optimum of one query with probability one requires choosing `a` with probability one. For target five, achieving the optimum of two queries with probability one requires choosing `p` with probability one. No randomized target-oblivious policy can satisfy both conditions.

The same conclusion holds for exact worst-case expected completion time: assigning positive probability to a non-optimal first action raises the relevant target's expectation above its exact optimum.

## 8. Rank/count metadata

The contradiction occurs before any first response has been observed. Additional metadata cannot tell the target-oblivious policy whether the external user will eventually stop at three or five discoveries.

The witness can also assign equal counts to the corresponding common tags and equal marker counts, so the identical-response branch remains identical even when counts are exposed. The deterministic returned order is already fully specified above.

Thus allowing rank and count observations does not remove this counterexample.

## 9. Scope

This is a definitive nonexistence proof for the exact universal-anytime objective **under Model M0**.

A stricter future model could add structural axioms that rule out this witness. If so, existence must be reconsidered under that narrower model. Examples might include special monotonicity, exchange, matroid-like, or adaptive-submodular properties strong enough to eliminate exploration/exploitation conflicts.

The result therefore changes the research program from "find the exact universal anytime-optimal policy" to one of the following mathematically meaningful questions:

1. What is the best achievable competitive ratio for a target-oblivious policy?
2. Is there a Pareto-optimal discovery curve with a canonical selection rule?
3. What is the strongest natural structural restriction under which exact anytime optimality becomes possible?
4. What computational resources are required to evaluate the best policy under those weaker objectives?
