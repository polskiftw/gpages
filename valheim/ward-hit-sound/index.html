Ward Hit Sound Toggle

Tiny client-side BepInEx plugin for Valheim. Press F8 to turn the ward hit/violation sound on or off while keeping the ward flash and protection unchanged.

Download

No GitHub account required. The ZIP contains WardHitSoundToggle.dll.

Install
  1. Install BepInEx 5 for Valheim.
  2. Extract WardHitSoundToggle.dll.
  3. Put it in Valheim\BepInEx\plugins\.
  4. Launch Valheim and press F8 to toggle the ward sound.

Client-side: yes
Server install: not required
Default key: F8
Config: BepInEx\config\claire.valheim.wardhitsoundtoggle.cfg
