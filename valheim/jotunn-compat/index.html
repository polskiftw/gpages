Jotunn Compatibility Layer

Drop-in Jotunn compatibility for existing Valheim mods, with expensive internals replaced incrementally instead of forcing mods onto a new framework.

Download JotunnCompat.zip

Recommended package. Contains the exact upstream Jotunn.dll plus JotunnCompat.FastPath.dll.

Remove a separately installed Jotunn package first. This ZIP already contains Jotunn, so loading another copy would duplicate the same assembly/plugin.

Install
  1. Install BepInEx 5 for Valheim.
  2. Remove the separately installed official Jotunn package if present.
  3. Extract JotunnCompat.zip into a folder under Valheim\BepInEx\plugins\.
  4. Keep Jotunn.dll and JotunnCompat.FastPath.dll together.
  5. Launch Valheim normally.
Compatibility strategy

The current build bundles the unmodified official Jotunn 2.30.1 DLL. The fast-path plugin loads after Jotunn's Awake and installs Harmony overrides before Jotunn's Start. Existing mods therefore get the exact Jotunn assembly, GUID, version, namespaces, types, methods, and network behavior they were compiled against.

Current fast paths

Obsolete PatchInit: skips the full reflection walk for dependent assemblies that cannot contain PatchInitAttribute.

Automatic localization: replaces five recursive BepInEx plugin-tree scans with one scan, and avoids initializing the localization manager when there are no automatic translation files.

Direct files
Jotunn.dll JotunnCompat.FastPath.dll
