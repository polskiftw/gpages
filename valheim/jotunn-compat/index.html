Jotunn Compatibility Layer

Drop-in Jotunn compatibility for existing Valheim mods, with generic internals optimized and hardened behind the same Jotunn contract.

Download JotunnCompat.zip

Recommended. The ZIP already contains the correct BepInEx/plugins and BepInEx/patchers folders.

Remove a separately installed Jotunn package first. If you tested the older compatibility prototype, also remove JotunnCompat.FastPath.dll.

Install
  1. Install BepInEx 5 for Valheim.
  2. Remove any separately installed Jotunn package.
  3. Extract JotunnCompat.zip directly into the Valheim game directory.
  4. The ZIP places Jotunn under BepInEx/plugins/JotunnCompat/ and the early compatibility layer under BepInEx/patchers/.
  5. Launch Valheim normally.
Compatibility strategy

The build bundles the unmodified official Jotunn 2.30.1 release DLL, pinned by SHA-256. A tiny BepInEx preloader arms before plugin discovery and installs generic Harmony hooks the instant the CLR loads the assembly named Jotunn—before any Jotunn-dependent mod can run Awake. Existing mods still bind to the exact upstream Jotunn assembly, GUID, API, and network behavior.

Current generic improvements

PatchInit: avoids pointless reflection on assemblies that cannot use the obsolete attribute.

Localization: replaces five recursive plugin-tree scans with one.

Prefab lookups: memoizes successful non-texture lookups without negative caching.

JVLmock references: avoids redundant depth-limited graph walks and repeated successful resolutions.

AssetManager: prevents Jotunn's known invalid-CodeMatcher collision from killing AssetManager when another mod has already transformed the same instruction.
