Jotunn Compatibility Layer

A source-built slim replacement for Jotunn that keeps the assembly identity and API existing Valheim mods expect.

Download JotunnCompat.zip

Recommended. The ZIP contains the complete plugin folder, including the slim Jotunn.dll and its YamlDotNet.dll dependency.

Remove official Jotunn first. Also remove obsolete prototype files such as JotunnCompat.Preloader.dll or JotunnCompat.FastPath.dll if you previously tested an older build.

Install
  1. Install BepInEx 5 for Valheim.
  2. Remove any separately installed official Jotunn package.
  3. Extract JotunnCompat.zip directly into the Valheim game directory.
  4. The ZIP installs under BepInEx/plugins/JotunnCompat/.
  5. Launch Valheim normally.
What this build is

This package does not contain the official Jotunn runtime. Jotunn.dll is our own source-built compatibility implementation. It preserves the Jotunn assembly name, BepInEx GUID com.jotunn.jotunn, and the public surface required by supported existing mods while replacing the backend with a smaller generic implementation.

Current backend coverage

Prefabs: lookup, cloning, registration, cache behavior, ZNetScene integration.

World locations: custom locations and ZoneSystem lifecycle registration.

Dungeons: custom rooms and dungeon themes.

Items: item and status-effect registration.

Assets: SoftReferenceableAssets lookup, runtime registration, and resolve-on-load handling.

Other: localization, custom RPCs, JVLmock-style reference fixing, GUI sprite lookup, and embedded-resource helpers.

Compatibility validation

CI builds against a SHA-256-pinned copy of the exact current Valheim Valheim_Data/Managed assemblies and validates the private game/SoftReferenceableAssets contracts used by the runtime. More World Locations AIO 5.1.1 is the first broad canary: its main assembly references 26 Jotunn types and 91 Jotunn members, all of which resolve against this slim build. Live in-game behavior still needs runtime testing.
