Server Torch Refill

True server-side Valheim light maintenance: refill torches, sconces, braziers and similar lights from nearby storage while vanilla and console clients install nothing.

Download ServerTorchRefill.dll

Hosted build: 2026-09-28 10:08:28 UTC

The DLL is installed only on the dedicated server. It requires ServersideQoL 2.1.1 or newer.

Install
  1. Install BepInEx 5 on the Valheim dedicated server.
  2. Install ServersideQoL 2.1.1+ and its required dependencies on the server.
  3. Download ServerTorchRefill.dll.
  4. Put it in the server's BepInEx/plugins/ folder.
  5. Restart the server. Clients do not install this mod.
Default behavior

Storage range: 10 m
Refill trigger: 25% fuel or lower
Refill toward: 100%
Fuel left behind: 0
Fallback check: every 30 seconds, plus immediate checks after nearby chest changes
Open chests: never modified
Fuel type: read from each Fireplace's real m_fuelItem; never hardcoded

What gets refilled

By default the processor handles refillable Fireplace prefabs whose prefab/localized names look like lighting: torch, sconce, brazier, candle, jackoturnip, or lantern. Infinite-fuel and non-refillable fireplaces are ignored. Set IncludeAllFireplaces = true if you also want campfires, hearths, bonfires and other refillable fireplaces fed from storage.

Server/network behavior

Uses the ServersideQoL container registry and ownership handoff instead of pretending the dedicated server always owns loaded objects. If a client currently owns a fuel chest, the server requests ownership and retries. The chest inventory is serialized back through the framework after fuel is removed, and the light's fuel is written to its authoritative ZDO.
