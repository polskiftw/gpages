Assembly Inspector

Browse Valheim's live assembly_valheim classes and return types, experiment with forced scalar return values, and generate standalone Harmony override mods directly from the method you found.

Download AssemblyInspector.dll

BepInEx 5 + Harmony. Default hotkey: F9. Version 1.2.0 can export every active live override together as one standalone postfix mod.

The CoolThing workflow

Find CoolThing, select IsAllowed() -> bool, then click Force TRUE live. The original method still executes, but every caller receives true. If you like the result, Copy postfix mod gives you complete standalone BepInEx/Harmony source for that exact method.

Browse

Search classes, methods, properties, and fields. Filter methods/properties by return type. See full parameter lists, visibility, static/virtual/abstract status, generic arity, metadata token, property getter targets, field types, and static field values.

Bundle all active overrides

You can keep multiple live overrides active at once. The top bar shows Copy live bundle (N), where N is the active override count. Clicking it copies one complete BepInEx/Harmony plugin containing every active method and its current forced value. Paste that source into the Valheim DLL Generator to turn the whole experiment into one DLL.

Two generated override styles

Postfix: runs the original method, then replaces its result. This is the safer default because original side effects still happen.

Hard override: supplies the forced result and skips the original method entirely.

Supported live values

Booleans, strings, chars, enums, decimal values, and primitive numeric return types can be forced live. Complex object-returning methods are still inspectable, but Assembly Inspector does not synthesize arbitrary replacement objects.

Install
  1. Install BepInEx 5 for Valheim.
  2. Download AssemblyInspector.dll.
  3. Put it in Valheim/BepInEx/plugins/.
  4. Enter a world and press F9.

Version: 1.2.0
Default assembly: assembly_valheim

Harmony: required (included with the normal BepInEx Valheim pack)
