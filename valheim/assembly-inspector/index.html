BepInEx 5 + Harmony. Default hotkey: F9. Version 1.5.0 adds scalar argument overrides and prefix/postfix field-mutation patches while keeping deterministic content-derived identities for exported live bundles.

The CoolThing workflow

Find CoolThing, select IsAllowed() -> bool, then click Force TRUE live. The original method still executes, but every caller receives true. If you like the result, Copy postfix mod gives you complete standalone BepInEx/Harmony source for that exact method.

Assembly-wide search

Use Global search without selecting a class first. Plain terms search class/member names, method signatures, return/property/field types, and parameter names/types. Narrow results with filters such as method:, field:, property:, class:, name:, type:, and param:. Selecting a result jumps directly to its owning class and normal detail panel.

Bundle all active overrides

You can keep multiple live patches active at once. The top bar shows Copy live bundle (N), where N counts active return overrides, argument overrides, and field mutations. Clicking it copies one complete BepInEx/Harmony plugin containing the whole experiment. Each distinct patch set gets a deterministic ID such as claire.valheim.generated.livebundle.a83f21d4c4e51290; exporting the same set again keeps the same ID. Paste that source into the Valheim DLL Generator to turn the whole experiment into one DLL.

Argument overrides + field mutations

Arguments: supported scalar parameters can be replaced in a Harmony prefix before Valheim receives them, such as forcing a cheated argument to false.

Fields: enter a one-level target such as this.m_cheated, item.m_cheated, or arg0.m_cheated, choose prefix or postfix timing, and set a writable scalar field. Private fields are written by reflection in generated mods.

Two generated override styles

Postfix: runs the original method, then replaces its result. This is the safer default because original side effects still happen.

Hard override: supplies the forced result and skips the original method entirely.

Supported live values

Booleans, strings, chars, enums, decimal values, and primitive numerics are supported for return forcing, argument overrides, and field writes. Complex object values remain inspectable, but Assembly Inspector does not synthesize arbitrary replacement objects.

Install
  1. Install BepInEx 5 for Valheim.
  2. Download AssemblyInspector.dll.
  3. Put it in Valheim/BepInEx/plugins/.
  4. Enter a world and press F9.
