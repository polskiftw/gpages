How this works

This page calls GitHub's workflow-dispatch API directly. Your browser token only needs permission to start/read Actions in this one repository. The Actions runner supplies the pinned Valheim/BepInEx/Harmony references, compiles the submitted source inside a fixed project, and publishes the resulting DLL under this Pages site.

Privacy note: the submitted source itself is not committed, but successful DLLs and failed compiler logs are published in this public repository's Pages build-results folder.
