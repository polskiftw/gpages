Hammer Everything

BepInEx-only Valheim mod that adds normally hidden vanilla props and structural pieces to the Hammer. Built for barrels, crates, furniture, banners, curtains, lanterns, location props, and other safe vanilla prefabs.

Download

Direct DLL download. No Jotunn dependency.

Install
  1. Install BepInEx 5 for Valheim.
  2. Download HammerEverything.dll.
  3. Put it in Valheim\BepInEx\plugins\.
  4. Launch Valheim and equip the Hammer.
What it does

Uses Valheim's original vanilla network prefabs and adds safe hidden ones to the Hammer at runtime. Added entries now get automatically rendered 128×128 thumbnails from their actual vanilla models, processed one per frame with the normal vanilla icon as a fallback. The automatic scan excludes creatures, projectiles, item drops, spawners, terrain generators, VFX, trees, rocks, pickables, ships, carts, wards, and other unsafe object classes. CargoCrate is specifically blocked because the vanilla object deletes itself when empty.

Jotunn: not required
Multiplayer: yes; builders install the plugin, placed objects retain vanilla prefab identities
Hidden-piece cost: free by default
Icons: unique model thumbnails with fallback
Dungeon placement: enabled by default
Config: BepInEx\config\claire.valheim.hammereverything.cfg

Advanced

Use ExtraPrefabNames in the generated config to add exact vanilla prefab names that the automatic prop scan does not recognize. Use BlockedPrefabNames to remove specific entries from the Hammer.
