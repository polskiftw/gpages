No Cheat Tags

Nuclear Valheim cheat-marker suppression: item flags are scrubbed, cheated arguments and ItemCheated checks are forced clean, the native bypass is forced in memory, character cheat-history markers are suppressed, and world-object cheat flags read/write as false.

Download NoCheatTags.dll

Hosted build: 2026-09-28 13:56:26 UTC

BepInEx 5 + Harmony. Version 1.2.0.

What it forces

ItemData.m_cheated: cleared on load, before save, through inventory load/save/add paths, before tooltip rendering, and by a periodic sweep of the live local-player inventory. Version 1.2.0 also falls back to directly scanning Inventory's enumerable fields when GetAllItems() is unavailable or insufficient.
cheated arguments: every boolean parameter literally named cheated in the Valheim gameplay assembly is forced to false.
ItemCheated(...): every bool-returning method with that name returns false.
PlayerProfile.s_bypassCheatChecks: returns true in memory without invoking the vanilla command or writing its saved bypasscheatchecks key.
PlayerProfile.m_usedCheats: existing values are cleared on profile load/save paths, the vanilla console write is removed from Terminal.ConsoleCommand.RunAction, and the active profile is scrubbed around command execution as a fallback.
PlayerStatType.Cheats: PlayerProfile.IncrementStat ignores this one stat and existing values are reset to zero across the profile's player-stat tracks.
ZDO cheat markers: s_cheated and the eight queued cheat slots cannot be written true and are read as false.

Existing inventory cleanup

Version 1.2.0 explicitly sweeps the already-live local player's inventory every 500 ms. This closes the hole where an inventory could already be in memory without passing through one of the patched load/add paths. When an existing m_cheated=true item is found, the actual field is set to false immediately and the plugin logs how many items it cleaned.

Persistence

Loaded item flags are actually cleared in memory and are clean when those items are next saved. Existing raw world-ZDO cheat bits are neutralized on read and new true writes are blocked; this first version does not bulk-rewrite untouched historical ZDO records just to remove dormant bits from the world file.

The vanilla dev bypass

The vanilla command persists a character key named bypasscheatchecks. This plugin does not use that command or setter; it patches the getter result in memory instead, so installing the plugin does not create that saved key. Existing keys are left alone.

Install
  1. Install BepInEx 5 for Valheim.
  2. Download NoCheatTags.dll.
  3. Put it in Valheim/BepInEx/plugins/.
  4. Restart Valheim.

For absolute world-side suppression on a dedicated/listen server, install it on the authoritative host/server too.
