Gear Inspector

In-game Valheim equipment browser and fitting room. Inspect the live ObjectDB, preview wearable gear on your character, and copy the exact prefab IDs and technical metadata you need for spawning or future mods.

Download GearInspector.dll

BepInEx 5 plugin. No Jotunn or Harmony dependency.

Install
  1. Install BepInEx 5 for Valheim.
  2. Download GearInspector.dll.
  3. Put it in Valheim/BepInEx/plugins/.
  4. Enter a world and press F8.
What it shows

Localized item name, exact prefab/spawn ID, Valheim stable hash, localization token, item type, category, variant count, set data, attach override, equip status effect, movement modifier, armor values, weight, and whether ObjectDB has a crafting recipe for the item. Search works across the useful identifiers.

Fitting room

Selecting gear can immediately equip a temporary cloned ItemData without adding anything to your inventory. The first preview snapshots your current equipped loadout. Mix multiple slots, cycle variants, take screenshots, then close the inspector or press Restore original gear to put the saved loadout back.

Developer bits

The item list comes from the game's live ObjectDB.m_items, not a hardcoded list, so normally registered mod-added equipment can appear too. Dump JSON writes the catalog to BepInEx/config/GearInspector/equipable-items.json. Copy buttons provide prefab IDs, basic spawn commands, and a complete technical block.
