NetHack Config Generator

Build a clean ~/.nethackrc for NetHack 5.0.0 on Gentoo. Enable only the settings you want written; everything else stays under NetHack's built-in defaults.

Port-aware, not port-confused. Gentoo always builds tty and curses; qt6 adds the Qt GUI and X adds X11. Port badges show where a setting is meaningful. This generator targets the Gentoo build, so Win32/MS-DOS-only knobs are intentionally omitted. Unsupported window-port options are generally ignored by NetHack.
