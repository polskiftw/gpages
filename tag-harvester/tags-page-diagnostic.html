Tags.php Diagnostic

A privacy-safe probe for the old-school tag listing page.

  1. Tap Copy diagnostic bookmarklet.
  2. Create a fresh Safari bookmark and replace its URL with the copied code.
  3. Open the logged-in tags.php page.
  4. Run the bookmark and tap Run diagnostic.
  5. Copy the sanitized report and paste it into ChatGPT.

Privacy: the report omits the hostname, full URLs, parameter names, tag names, and raw HTML. The diagnostic only reports pagination structure, row counts, direct-fetch behavior, and whether common page-size overrides work.
