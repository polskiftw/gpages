Tag Gremlin Discovery Diagnostic

A privacy-safe local reconnaissance pass for alternate tag/list/index surfaces.

  1. Tap Copy discovery bookmarklet.
  2. Create a fresh Safari bookmark and replace its URL with the copied code.
  3. Open the logged-in site.
  4. Run the bookmark, tap Start 12-second discovery scan, then use the site's tag/search/browse UI normally for those 12 seconds.
  5. When it finishes, copy the sanitized report and paste it here.

Privacy: the report deliberately omits hostname, URLs, paths, query/field names, tag names, and raw responses. The tool inspects same-origin network traffic and JavaScript locally, then reports only structural features such as array sizes, JSON shape, pagination signals, and whether alternate API/tag-related code appears to exist.
