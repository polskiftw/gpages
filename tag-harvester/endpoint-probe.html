Tag Gremlin Endpoint Probe v2

Fixed, shorter endpoint diagnostic. Numeric-leading tags are treated as valid.

  1. Tap Copy endpoint probe v2.
  2. Create a fresh Safari bookmark named Tag Gremlin Endpoint Probe v2.
  3. Replace its URL with the copied code.
  4. On the logged-in search page, tap the Tags field once and run the bookmark.
  5. Tap Run probe, then Copy safe report.

Privacy: the copied report omits the site, endpoint path, the site's own query-key name, tag names, and raw JSON. The probe only performs read-only GET variations locally in Safari.
