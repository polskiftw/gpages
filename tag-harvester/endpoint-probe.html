Tag Gremlin Endpoint Probe v3

Checks the remaining things that can change the minimum-query algorithm: response metadata, digits, and punctuation searches.

  1. Tap Copy endpoint probe v3.
  2. Create a fresh Safari bookmark named Tag Gremlin Endpoint Probe v3.
  3. Replace its URL with the copied code.
  4. On the logged-in search page, tap the Tags field once and run the bookmark.
  5. Tap Run probe, then Copy safe report.

Privacy: copied output omits the site, endpoint path, site field names, tag names, and raw JSON. All structural inspection happens locally in Safari.
