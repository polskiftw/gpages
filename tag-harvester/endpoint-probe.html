Tag Gremlin Endpoint Probe

Privacy-safe follow-up diagnostic. It tests the autocomplete endpoint locally for larger limits, hidden pagination, and empty-query behavior.

  1. Tap Copy endpoint probe.
  2. Create a fresh temporary Safari bookmark named Tag Gremlin Endpoint Probe.
  3. Replace its URL with the copied code.
  4. On the logged-in search page, tap the Tags field and run the bookmark.
  5. Tap Run probe, then Copy safe report and paste it into ChatGPT.

Privacy: the copied report omits hostname, URL/path, raw query-parameter names used by the site, tag names, raw JSON, cookies, headers, and request/response bodies. Real values are used only transiently in Safari so the probe can compare results locally.
