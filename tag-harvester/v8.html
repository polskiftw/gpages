Tag Gremlin v8

Language-guided harvesting with v7's hard completeness proofs.

Install

  1. Pause + Save v7 first so its newest local progress is committed.
  2. Wait for this page to say v8 bookmarklet ready.
  3. Tap Copy v8 bookmarklet.
  4. Create a fresh Safari bookmark named Tag Gremlin v8 and replace its URL with the copied code.
  5. Reload the logged-in target page, run the v8 bookmark, then tap Start / Resume.

What v8 does differently

v8 automatically imports saved v7 tags, proven closed substrings, saturated proofs, and the learned same-origin JSON endpoint into a separate v8 database. It learns a tiny local language model from the harvested corpus: known prefixes, character n-grams, sibling productivity, and a weak popularity weighting. That model controls order only; it never gets permission to prune a branch.

The scheduler alternates between harvest mode for language-like productive candidates and prune mode for short sparse candidates likely to close large regions. The ratio changes automatically as new-tag yield falls, and a depth horizon prevents the language model from diving arbitrarily far ahead of shorter completeness proofs.

Safety + instrumentation

Only a real autocomplete result below the measured hard cap of 40 can close a substring. The existing ≥40-known exact-tag inference remains the only zero-request saturation proof. The live panel shows scheduler mode, frontier depth, moving new-tags-per-request yield, request latency, tags/minute, requests/minute, free inferences, and an eight-line decision history. An invariant guard blocks any attempted request containing a substring already proven closed.
