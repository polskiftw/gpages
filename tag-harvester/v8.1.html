Tag Gremlin v8.1

v8's language-guided harvesting, now with a frontier-debt controller that forces convergence when unresolved work starts compounding.

Install

  1. Pause + Save v8 first.
  2. Wait for v8.1 bookmarklet ready.
  3. Tap Copy v8.1 bookmarklet.
  4. Create a fresh Safari bookmark named Tag Gremlin v8.1 and replace its URL with the copied code.
  5. Reload the logged-in target page, run v8.1, then tap Start / Resume.

Your v8 run resumes exactly where it left off

v8.1 intentionally uses the same local v8 IndexedDB and the same proof records. It does not restart the crawl or re-query completed fragments. The new code only changes scheduling and instrumentation.

Frontier debt

v8.1 measures unresolved frontier size relative to the harvested corpus and also learns the moving net frontier change per resolved candidate. Normal mode still mixes language-guided harvesting with pruning. If the frontier becomes disproportionately large, v8.1 enters FRONTIER DEBT MODE: harvest requests temporarily stop, pruning becomes shortest-depth-first, and the scheduler targets candidates that balance high closure probability with useful global coverage. Hysteresis keeps it in debt repayment until the frontier has genuinely fallen rather than bouncing in and out.

Still mathematically safe

Language, popularity, frontier pressure, and sibling history affect order only. A real response below 40 is still the only thing allowed to close a substring. The ≥40-known exact-tag inference remains the only zero-request saturation proof. The invariant guard still blocks any request covered by a CLOSED substring.
