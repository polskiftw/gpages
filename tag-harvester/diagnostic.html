Tag Gremlin Diagnostic

A temporary bookmarklet that measures autocomplete behavior before we design the minimum-query crawler.

Install

  1. Tap Copy diagnostic bookmarklet.
  2. Create a temporary Safari bookmark named Tag Gremlin Diagnostic.
  3. Replace its URL with the copied code.
  4. Open the logged-in search page, tap the Tags field once, then run the bookmark.
  5. Tap Run diagnostic. When it finishes, tap Copy report and paste the report back into ChatGPT.

What it checks

It performs a small fixed set of autocomplete searches without saving tags or touching Tag Gremlin's IndexedDB. It measures the observed suggestion cap, count ordering, substring/fuzzy behavior, shortest returned tag, exact-match behavior, and watches fetch/XHR/resource traffic to identify the autocomplete endpoint and any visible pagination parameters such as limit, offset, page, or size.
