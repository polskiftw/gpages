Tag Gremlin Private Diagnostic

v2 — measures the autocomplete locally, but produces a deliberately redacted report.

Install

  1. Tap Copy private diagnostic.
  2. Create a temporary Safari bookmark named Tag Gremlin Diagnostic v2.
  3. Replace its URL with the copied code.
  4. Open the logged-in search page, tap the Tags field once, then run the bookmark.
  5. Tap Run diagnostic, then Copy safe report and paste that report into ChatGPT.

Privacy behavior

The report never includes the site hostname, URL/path, raw request or response bodies, cookies, headers, or any discovered tag name. Tag strings and network details exist only temporarily in the page's memory so the diagnostic can compare them locally. Nothing is uploaded by this bookmarklet. The copied report contains only aggregate behavior, lengths, positions, transport/method classification, same-origin yes/no, and generic pagination-field detection.
