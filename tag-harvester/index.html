v6 changes

v6 keeps every branch, but changes the order intelligently. Known tag counts rank promising two-character searches; full result lists spawn every child as before, while children suggested by high-count results jump toward the front. It also harvests valid substring matches instead of throwing them away. To make that safe, v6 preserves all tags already collected by v4/v5 but rebuilds crawl progress once, because the old prefix-only result counts are not compatible with the smarter substring-aware crawl. Screen wake lock and 25-query IndexedDB batching remain.
