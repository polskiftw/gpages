Tag Gremlin

Desktop harvester for the complete tag index and synonym map. The old bookmarklet version is preserved below, but the desktop CLI is the recommended version now.

Desktop setup — no repo clone needed

You can put Tag Gremlin anywhere on your Gentoo box. This creates ~/tag-gremlin, downloads the single Python file from gpages, and runs it there.

1. Download Tag Gremlin

mkdir -p ~/tag-gremlin cd ~/tag-gremlin curl -fLO https://raw.githubusercontent.com/polskiftw/gpages/main/tag-gremlin/tag_gremlin.py

2. Make sure Firefox is logged in

Open Firefox normally and log into the target site first. When you start Tag Gremlin, it now automatically closes Firefox cleanly, reads the matching cookies from cookies.sqlite, then reopens the same Firefox profile for you. Cookie values are not printed or saved into the Tag Gremlin database.

3. Start the harvest

Replace YOUR-SITE with the real hostname. Point it at the site's normal tags.php page.

cd ~/tag-gremlin python3 tag_gremlin.py \ --db ~/tag-gremlin.sqlite3 \ harvest \ --url 'https://YOUR-SITE/tags.php' \ -8

Safe to interrupt: completed pages are committed to SQLite as it goes. Run the same harvest command again to resume. After a COMPLETE: YES crawl, running the same command weeks later starts a fresh refresh generation automatically.

Do not delete ~/tag-gremlin.sqlite3 unless you intentionally want to start over from scratch.

Check progress / verify / export

Status

cd ~/tag-gremlin python3 tag_gremlin.py --db ~/tag-gremlin.sqlite3 status

Strict verification

cd ~/tag-gremlin python3 tag_gremlin.py --db ~/tag-gremlin.sqlite3 verify

The harvest only reports COMPLETE: YES when every expected page is accounted for, the unique TagID count and page-row totals reconcile with the site, and every harvested synonym count matches the site's reported count. TagID is the stable identity.

Export files

cd ~/tag-gremlin python3 tag_gremlin.py \ --db ~/tag-gremlin.sqlite3 \ export \ --out-dir ~/tag-gremlin-export
  • ~/tag-gremlin-export/tags.txt — one official tag per line; this is the simple corpus for the regex/search tool.
  • tags.tsv — TagID, name, uses, votes, synonym count.
  • synonyms.tsv — source official tag → raw synonym, plus resolved target TagID/name and resolution status.
  • synonym-map.tsv — the same relationship with the synonym string first.

What the desktop version does

resumable SQLiteFirefox authsynonym mapstrict verification

  • Harvests the directly pageable tags.php?page=N index instead of brute-forcing autocomplete.
  • Stores the full tag corpus locally in SQLite.
  • Keys tags by TagID rather than page number, so tags can move between pages on later refreshes without creating duplicates. A completed refresh UPSERTs known TagIDs and removes old TagIDs no longer seen only after verification succeeds.
  • Keeps every raw synonym string and, after a complete crawl, resolves it to a target TagID only when it exactly matches one unique current official tag name. Missing or ambiguous names stay explicitly unresolved rather than being guessed.
  • Captures TagID, official name, uses, positive/negative votes, reported synonym count, and the hidden synonym data already embedded in each page.
  • Uses the fixed worker count you choose (for example -8). Workers share one non-overlapping page queue; only the request that hits a timeout/429/transient error backs off while the others keep moving.
  • Stops rather than silently accepting parser drift or synonym-count mismatches.

The complete design notes live in tag-gremlin/DGD.md. The source is tag_gremlin.py.

Legacy bookmarklet — Tag Gremlin v9

Preserved for old phone/browser crawls. This is no longer the recommended way to build a fresh corpus on desktop.

Install / upgrade legacy v9

  1. If v8 or v8.1 is running, tap Pause + Save first.
  2. Wait for v9 bookmarklet ready below.
  3. Tap Copy v9 bookmarklet.
  4. Create a fresh Safari bookmark named Tag Gremlin v9 and replace its URL with the copied code.
  5. Reload the logged-in target search page and run the new bookmark.
  6. Tap Start / Resume. If it needs to relearn the autocomplete endpoint, tap the Tags field once and run it again.

Legacy v9 notes

No restart. v9 intentionally uses the same tag-gremlin-v8:<host> IndexedDB as v8/v8.1. Existing tags, CLOSED proofs, saturated queries, request counters, learned endpoint data, frontier-pressure state, and debt state are loaded and the frontier is rebuilt from that saved work.
