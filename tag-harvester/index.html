Tag Gremlin v9

The restored frozen v9 control scheduler, packaged again as an iPhone Safari bookmarklet. It resumes the existing v8/v8.1 crawl database.

Install / upgrade

  1. If v8 or v8.1 is running, tap Pause + Save first.
  2. Wait for v9 bookmarklet ready below.
  3. Tap Copy v9 bookmarklet.
  4. Create a fresh Safari bookmark named Tag Gremlin v9 and replace its URL with the copied code.
  5. Reload the logged-in target search page and run the new bookmark.
  6. Tap Start / Resume. If it needs to relearn the autocomplete endpoint, tap the Tags field once and run it again.

Your scan resumes

No restart. v9 intentionally uses the same tag-gremlin-v8:<host> IndexedDB as v8/v8.1. Existing tags, CLOSED proofs, saturated queries, request counters, learned endpoint data, frontier-pressure state, and debt state are loaded and the frontier is rebuilt from that saved work.

v9 corrections

0–9 roots keptperiod kepthyphen removed

  • Tags beginning with a digit remain fully supported.
  • The valid crawl alphabet is now a–z, 0–9, and period.
  • Old v8/v8.1 tag or proof records containing a hyphen are ignored when v9 rebuilds the active crawl, so they cannot spawn useless descendants.

What “v9” means here

This uses the preserved v9 control policy from the later research harness: the same language/popularity scoring, sibling evidence, harvest-vs-prune scheduling, frontier-pressure controller, and debt-mode thresholds that were frozen as the v9 baseline. The only intentional behavior change is the corrected no-hyphen alphabet.

Completeness rules unchanged

A real autocomplete response below 40 is the only server response allowed to prove a substring CLOSED. A candidate that is itself a known tag and already occurs in at least 40 known tags may still be inferred saturated with zero request. CLOSED substrings continue to prune every covered candidate globally.
