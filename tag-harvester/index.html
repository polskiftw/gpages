Tag Gremlin

Self-contained iPhone Safari autocomplete harvester.

Update the bookmark

  1. Tap Copy updated bookmarklet.
  2. Edit your existing Tag Gremlin bookmark.
  3. Delete its old URL and paste the new one.
  4. Return to the logged-in search page and run the bookmark.

What changed

This version only assumes tags begin with a–z. Because the site appears to require at least two typed characters before showing suggestions, it starts with two-character prefixes. Later characters may include letters, digits, spaces, periods, underscores, hyphens, and apostrophes. It saves after every query.
