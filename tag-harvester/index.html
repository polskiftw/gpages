Tag Gremlin

A resumable iPhone-friendly autocomplete harvester. It walks tag prefixes, collects suggestions and their counts, and stores progress in the target site's local storage.

Install on iPhone Safari

  1. Bookmark this page.
  2. Open Safari's bookmarks, edit that bookmark, and rename it Tag Gremlin.
  3. Delete the bookmark's URL and paste the code copied below.
  4. Open the logged-in target site and tap the Tag Gremlin bookmark.

If the target site blocks scripts loaded from GitHub Pages, the bookmarklet will tell you. That just means we need a self-contained fallback.

Using it

Tap Start / Resume. It first probes broad prefixes to learn how many autocomplete results the site returns, then recursively splits crowded prefixes until branches are exhausted. It saves after every query, so Safari suspending the tab does not wipe the run. Use Copy tags or Export JSON whenever you want a snapshot.
