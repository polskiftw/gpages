Tag Gremlin

Self-contained iPhone Safari autocomplete harvester.

Update the bookmark again

  1. Tap Copy v3 bookmarklet.
  2. Edit your existing Tag Gremlin bookmark.
  3. Replace its URL completely.
  4. Return to the logged-in search page and run it.

What changed

v3 no longer just assigns text to the Tags box. It types each character in sequence and fires the keyboard/input events autocomplete widgets normally listen for, including jQuery events when jQuery is present. It also waits for the server response instead of assuming a fixed delay. Use Test “br” first: because you confirmed “br” produces suggestions manually, that gives us an immediate pass/fail test before starting the full crawl.
