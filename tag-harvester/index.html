Tag Gremlin

v5 — IndexedDB-backed iPhone Safari autocomplete harvester with screen wake lock.

Make a fresh v5 bookmark

  1. Tap Copy v5 bookmarklet.
  2. Create a new Safari bookmark named Tag Gremlin v5.
  3. Replace that bookmark's URL with the copied code.
  4. Return to the logged-in search page and run it.

v5 changes

Start / Resume now requests a screen wake lock so the display stays awake while the crawler is running. Pause + Save and a completed run release it. If Safari temporarily releases the lock after the page loses visibility, v5 tries to reacquire it when the page becomes visible again. It keeps the same IndexedDB data as v4, so existing v4 progress can continue. Valid tag characters remain a–z, 0–9, period, and hyphen; the first character is restricted to a–z.
