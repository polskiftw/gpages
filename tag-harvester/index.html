Tag Gremlin

Self-contained iPhone Safari version. No external script loading, so strict sites cannot block the GitHub file.

Replace your old bookmark URL

  1. Tap Copy self-contained bookmarklet.
  2. Open Safari bookmarks and edit your existing Tag Gremlin bookmark.
  3. Delete the old URL completely and paste the new one.
  4. Return to the logged-in search page and tap Tag Gremlin from Bookmarks.

Then

A dark Tag Gremlin panel should appear directly on the search page. Tap Start / Resume. Progress is saved in that site's local storage after each query.
