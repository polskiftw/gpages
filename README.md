# gpages

Small static browser tools hosted with GitHub Pages.

## Structure

- `/index.html` — landing page
- `/terraria-shopping/` — Terraria Shopping acquisition planner
- `/boolean-search/` — Boolean Search Builder
- `/tag-harvester/` — Tag Gremlin

Each tool should live in its own folder with its own `index.html` so the repository stays tidy as more tools are added.
